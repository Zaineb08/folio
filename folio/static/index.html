    Find a source

    Paste a sentence from your draft. Folio looks through your library for passages that support it or disagree with it, and shows you what they say.

    Literature matrix

    One row per paper, one column per question, so you can compare papers side by side. Each cell is a short note from that paper's own pages.

    Download for Excel

    Cells are written by the model on this PC from up to 4 passages of each paper: its opening and the 3 that best match the column. Click a page number to check the note against the paper before you rely on it. "Not stated" means those passages didn't say, not that the paper doesn't.

        Use Claude for answers

        Claude needs an API key from Anthropic. A claude.ai subscription doesn't include one: the API has its own account and prepaid credit, at console.anthropic.com.

        • What leaves this PC: the passages found for each question, plus the question. Only while Claude is selected.
        • Cost: each answer shows what it cost. Your local model stays free.
        • Your key: Folio checks it with Anthropic, then keeps it in Windows Credential Manager, not in a file.
